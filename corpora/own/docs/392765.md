# There is a problem with the [problem-user] tag

We have the problem-user tag, with excerpt that reads:

This tag should be used in a question about a user who has been causing problems like spamming, unproductive answers, using abusive language and starting comment wars.

While technically valid and "nice to have" tag that might add meta info to the question, I don't feel comfortable with the phrase itself "problem user", which might encourage people to mention the specific user when posting the question, which isn't good and isn't allowed.

The combo abuse with users is good enough, and fits perfectly to describe a question about users who have problematic behavior. The abuse tag excerpt says:

This tag is for questions concerning actions leading to bad behaviors or bad purposes, considered or suspected to be against Stack Exchange policies or the collaboratively philosophy of any Stack Exchange site.

Which should fit questions about users as well.

Should we burninate the problem-user tag and replace it (if relevant) with the above two tags instead?
