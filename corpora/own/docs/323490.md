# Show off-topic reasons for currently selected site instead of Software Engineering

Let's say I'm creating a new SEDE query for Meta Stack Exchange. The CloseAsOffTopicReasonTypes table has a nice 'show contents' icon, which saves me from having to execute SELECT * FROM CloseAsOffTopicReasonTypes:

but when you click it, you always see the contents of the table on Software Engineering.

I'd like for it to show the contents from the database of the currently selected site.

Another table which has this problem is PostNoticeTypes, though it's less severe here; there are a few sites like Skeptics, The Workplace and Worldbuilding which have their own custom post notices.
