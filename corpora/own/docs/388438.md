# Don't include the username as a part of the candidate statement

The candidate statement on the moderator election page contains the username of the candidate as a header part of it by default. You can manually remove it, but almost nobody does it. For instance, look at nomnoms12's candidate statement. On the full size page mode that looks fine:

But if you open it in narrow width mode, you will see the following:

As you can see, the username is doubled. That's because the top one is generated by the site engine (actual username), and the bottom one is taken from the candidate statement.

To make both versions (full site and narrow mode) uniform in that part, I suggest removing the auto-added header part from the candidate statement (e.g., as it was three years ago), and adding the title (user name) by engine on full site mode as well.

For instance, my own candidate statement doesn't have a header part (I removed it manually), and that's how it looks in full site mode:

Without a header/title it is hard to understand if it's the beginning of another candidate statement or not.
