# Winter Bash hat causes User Card Overflow™ on old self-answers

In case of a self-answer, the user card for the answer has a blue background. In the latest Firefox on macOS Monterey, the Winter Bash hat moves the 'answered' information to the right, making it overflow this background. This is only noticeable for old answers where the year is shown; here is an example:

Before the Winter Bash features load (I'm on a rather slow connection), it is shown normally. I am not able to reproduce it in other browsers.
