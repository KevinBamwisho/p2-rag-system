However, in the global search on stackexchange.com, this stat is being reset whenever searching again; choosing the items per page affects only that single search:

I assume this is because stackexchange.com is not attached to an ordinary account behind the scenes, so can't use the same server side cache. This can be bypassed by using a different cache probably, or by using the network profile if possible.
