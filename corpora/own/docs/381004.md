# Remember the profile tab I last visited

When I click another user's profile from the question list or from a post, 99% of the time I want to see how they recently have been interacting with the site, i.e. Activity --> All actions --> All.

However, clicking a username always defaults to showing their profile page, showing (above the fold) their badges and top tags. This takes two clicks and some waiting time to get me to the page I want to.

So: can the sites please remember which tab (Activity) and subtab (All actions) and subsubtab (All) I last viewed on any profile, and apply that to all future profile visits (including my own)?
