# Let asker see the upcoming closure directly and notify them about it

Some time ago you've added the funny New Contributor label so how about making for a change something that would be more helpful to everybody.

I'd like to suggest a feature where askers could see the upcoming closure right away, without having to click the "close" button and be notified about this fact.

I bet most users who are here for the first time don't know that there might be something hidden in the background. I think they would be able to react much quicker to it and improve their question before it gets closed. They also wouldn't be surprised a couple of hours or days later after the question got closed.

This would make life easier for everyone because currently many of us try to write comments to let the asker know what is wrong and let them fix the question while it's being voted upon. With the new feature this would be unnecessary and the asker could instantly see that the question might need to be fixed.
