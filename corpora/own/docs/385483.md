# Increase the visual difference between non-visited and visited links on stackexchange.com

On stackexchange.com (not meta.stackexchange.com or other subdomains), non-visited links have the color #366FB3, and visited links have the color #12457C.

I find the difference very difficult to see- much more difficult to see than on other network sites.

Can the visual difference please be increased?

I was just going through a list of many posts in the network-wide search and it was hard to see which links I had already visited.

Suggestions:

I think darkening the visited links might make it too dark. The color for visited links seems to already be quite similar to the color of regular text.

It might be better to lighten and/or increase the saturation for non-visited links (in which case, make sure to make sure that the difference between the color of non-visited link and the color of links that are being mouseovered (#4CA3D7) does not become too small (i.e. in this case, also adjust the mouseovered-link color accordingly)).

As suggested in the comments, just using a different color for visited links also works, and is quite conventional (at least- outside of SE sites).
