# JS broken on older web browsers due to undefined 'globalThis'

It seems a recent change in StackExchange has rendered it no longer working correctly on my browser (Firefox 60.7esr). The error message is:

ReferenceError: globalThis is not defined

As a result, most actions that requiring JS support such as voting, expanding comments, and leaving comment, has stopped working on affected browsers.

Can StackExchange add a fallback mechanism to support such silently older browsers? May be a polyfill of globalThis implemented at https://mathiasbynens.be/notes/globalthis?
