# Tags linked in the site maintenance banner can be updated to avoid synonym tags

During Site Maintenance there is a banner for read-only mode, which contains the following content.

This site is currently in read-only mode. We’ll return with full functionality soon. Visit our status page or search our recent meta posts on the topic for more info.

The link referred to the following URL:

https://meta.stackexchange.com/questions/tagged/maintenance+or+site-maintenance?tab=Newest

The URL contains two tags, such as maintenance and site-maintenance. But technically "site-maintenance" is a synonym for the "maintenance" tag.
So, it results in the search result being "Tagged with maintenance or maintenance".

I suggest changing the URL as follows; this will also result in the same search result:

https://meta.stackexchange.com/questions/tagged/maintenance?tab=Newest
