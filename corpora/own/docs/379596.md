# The 'Share', 'Edit', 'Follow', and 'Flag' buttons are not obvious

I've been using Stack Exchange for a few years intermittently, and I have found myself searching the entire screen scrolling up and down for these buttons on various occasions. I'm not a UI expert, but wouldn't it make more sense to place them at the top right of a post with an obvious difference of some sort like an icon?
