# How do bounties on closed questions work?

I answered a question with a bounty and my answer was accepted, but the question was closed (it was flagged as needing to be more focused). What happens to the bounty? I didn't get it, and now there seems to be no trace of it.

Answer in question: Detecting pattern in OHLC data in Python

EDIT - This isn't actually a duplicate of the linked question. The referenced question refers to a bounty that was awarded and then lost, while this one refers to a bounty on an accepted answer that was never awarded. Details are however clarified in How does the bounty system work, in the section What happens if a bounty question is closed or deleted?

It turns out a moderator refunded the bounty and closed the question, and the OP accepted my answer shortly after. The bounty had to be refunded to close the question. Since the bounty had already been refunded and the question closed, the bounty was not awarded.
