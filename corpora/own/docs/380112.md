# Is adding a Back button and/or a Next Question button a good UI/UX decision?

In terms of UI/UX it is a good decision, also for accessibility reasons. But is it worth the screen space it takes?

To clarify, I'm talking about a Back button that would take you the previous questions page. The same for Next Question button, only this would take you the next question in the order of the previous questions page. Everybody knows what these buttons are.

On the other hand, not many websites have those. Some do. Let's take a website with listings page and a single entry page. Hmm... Amazon and eBay have a "back to results" button. Google Images has a "Next result" arrow.

Indeed it's a matter of opinion. What do you think?
