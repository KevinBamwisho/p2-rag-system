# Adjust/don't show pro-tempore election notification if there is no election phase

Woodworking Stack Exchange just had its first pro-tempore election. Well, not really; there was no election phase since there was only one candidate for one seat. Therefore, the election ended as soon as it started (2019-03-25 20:00 UTC). Still, I received an inbox notification asking me to cast my vote:

It's great that the system is already smart enough to determine that an election phase is not needed (this wasn't the case before) but it would be nice if the inbox message is either not sent, or somehow altered to a message stating that you would've been able to vote except the election phase is being skipped for this election.
