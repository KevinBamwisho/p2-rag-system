# New notification system still feels counterintuitive

This has been bugging me for ages—I guess since October 2022: while it's good that the notifications were made more "sticky", I sometimes feel they are a bit too sticky. It's hard to pin down the problem precisely, but the user interface is still a bit counterintuitive, even for an experienced user after half a year.

Specifically, if someone posts two replies to one of my questions or answers, then I get two notifications in my inbox. So, I click on one of them, read both replies, and then I'm happy, right?

But now I still have one notification in my inbox. I've read it, but it's "unread", and I always have to spend a couple of minutes working out how to make it go away.

I know that I can press "mark all as read", but for some reason I never see or think of that button. So I end up having to click on the "unread" notification, thus reloading the page that I'm already looking at, just to make it go away.

In writing this post, I realised that I can also click on the little envelope icons next to each post to mark them as read individually. This is probably really useful. But I decided to post this anyway, because in seven months it never occurred to me that those icons might be clickable, and I'm sure I can't be the only one.

TL;DR: after half a year I still find the new notification UI frustrating and counterintuitive sometimes, and I wonder if it might be worth revisiting the user experience a bit.

I also want to mention that my habit is always to option-click on the notifications, opening them in a new tab behind the current one, then go through each tab one by one. My expectation is that having done that I will no longer have any notifications left, but in fact I often do. It might be that this habit of mine is causing my issue somehow. But I don't want to change it—I think it's a reasonable way to use the system and should be supported.
