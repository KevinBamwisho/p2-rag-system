# Direct links to Stack Exchange profile subtabs look bad

In a StackExchange.com profile, you can directly link to a tab like Favorites just fine. But when you try to link to the votes subtab under that, it doesn't look right because it's not the entire page (most of the navigation is missing, such as the top bar) and nothing is stylized:

This also happens with the activity subtabs. Note that clicking them is OK (and the URL doesn't actually change), but opening the link in a new window will show this bug.
