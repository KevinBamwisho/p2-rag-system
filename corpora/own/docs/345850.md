# How can I explicitly show the return value of a code snippet/sample

Is there an commonly accepted way (best practice if you wish) to show the return value of example code in markdown?

One solution is to add a comment at the end of the function, but I am concerned that this adds unnecessary text when people are copy-pasting, especially when the snippet is multiple lines long.

String.fromCharCode(parseInt("ff", 16)) // returns ÿ

I think this is usually a good situation for Code Snippet instead of Code Sample. However, sometimes you will still want to explicitly show the return value.

If you were referencing the return value interspersed with regular text, would it be appropriate to format the return value as inline code, e.g.

"The following function takes the hex number ff and returns the character ÿ"?
