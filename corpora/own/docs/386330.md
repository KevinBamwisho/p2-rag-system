# Allow more than 5 tags if red tags are used

As many of you should know that using a more than 5 tags simultaneously on the single question isn't possible:

Hence once a moderator decides to add a red tag (e.g. any of [status-...]) on the question with 5 tags, they need to think which tag to remove, like here:

Such type of action reduces the author intent and make tag filtering less efficient. Mod should decide which tag is less relevant to the question before delete them.

So, my suggestion is to allow to use more than 5 tags on the question if there're red tags exist.
