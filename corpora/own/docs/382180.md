# Inline tag editor disappears after live refreshing a question

The inline tag editor unlocked with access to moderator tools allows for quick and convenient editing of tags.

However, recently the editor link disappears after a live refresh of the question requiring the page to be reloaded to be back. See demonstration:

Furthermore, after the refresh pressing the keyboard shortcut T for the inline tag editor does not open it, either.

This used to happen only if after the live refresh there would be a pending suggested edit on the post. That is not the case here - you can see "Edit" does not change to "Edit (1)" to indicate a pending edit.

I do not know when exactly this bug started happening. All I know is that it is fairly recent. It presents a problem when trying to edit the tags of a question which received an edit.
