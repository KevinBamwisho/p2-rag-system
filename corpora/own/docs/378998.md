# Is there interest in adding a "visual glossary" to the glossary wiki (so we can better know the names of things when we discuss them)

I have been in several discussions/exchanges about SE that have been severely impeded because we spent much time and energy trying to figure out what literally each other was talking about.

We didn't have a shared set of names for anything, so we would either make up descriptive names, sometimes based on appearance (e.g. that red circle with the number in it = "inbox notification"?) or a notification that the post on the page you're looking at is being edited, or the notification on the main question page that a new question has been asked or an edit has been made.

Is there interest in adding a place where we can look up the actual SE names of visual elements on pages and site functionalities without already knowing their names?

Based on several comments below, perhaps adding it to the community wiki Stack Exchange Glossary - Dictionary of Commonly-Used Terms?

One option are a few annotated screenshots with perhaps little numbers and a table below with the numbers and the corresponding name, and perhaps even link to the line in the alphabetical glossary.

But perhaps a better option mentioned by @Rob here might be for small images (e.g. or ) to appear with or alongside the definitions in the existing glossary wiki.

This would add functionality and utility to the wiki because now even if you don't know the official name of what you are looking for you can still find it and it's name and description.

This can enhance our ability to have a shared set of names for things which may help advanced users and beginners alike to communicate about the site's workings amongst themselves and each other.
