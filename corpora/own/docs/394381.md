# Could we get an image resizer built into image upload, please? Please!

Many users will want to load photos directly from their phones. With modern phone camera resolution, SE will usually block these and tell the user the image must be resized first.

Many cell-phone users honestly do not know how to change resolution, and even for those who do this may mean having to send the image to another machine for processing, which is a non-trivial inconvenience.

It really should be easy for SE to instead automatically convert images to a standard size, and not much harder to only convert those which are oversized. Tools and libraries to do this are near-universally available.

I honestly don't see a significant reason not to automatically resize. If you are worried about DOS attacks you can still reject images which are completely unreasonable.
