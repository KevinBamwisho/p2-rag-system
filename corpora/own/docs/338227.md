# Some improvement suggestions for the Reputation value change email

Yesterday, I received an email about the reputation value change.

When viewing the mail in the standard iOS Mail app (on an iPhone 7 Plus, if it matters), the gray background isn't as wide as it should be, which makes the footer look kinda awful:

Second, "across Stack Overflow" is a bit confusing. It could imply that only a single site would be affected. I understand you want to use Stack Overflow as a brand name, which is why the email isn't titled "Reputation values are changing across Stack Exchange", but in the future, can you at least add the word "network"? E.g.

Reputation values are changing across the Stack Overflow network
