# How to handle SO copycat fraud site?

I was just searching for a programming solution via duckduckgo and by clicking one of the top results I ended up on stackoverflowhot.com. This website is an exact copy of Stackoverflow.com and only when I could not upvote an answer, I noticed that it is not the original SO website.

I think this is potentially dangerous. While I did not encounter any atempt to trick me into entering my password or install malware, I assume the intentions of the site owners are not good. Also I guess they are infringing on the copyright of SO and SO users.

So besides from raising awareness of this page, my question is: Is there any way to report this (besides reporting it as spam on duckduckgo)? Does Stackexchange Inc. have any policy on encountering such clickjacking sites?
