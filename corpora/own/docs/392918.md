# Is there a consolidated source of accessibility guidelines for users posting questions/answers?

While Stack Exchange itself tries to be as accessible as possible, I have been unsuccessful in finding anything to help users in their posting accessible questions/answers.

Is there a consolidated source, like the Markdown Help page, that helps the user in formatting their questions/answers for accessibility?

Some of the common issues I have seen are:

Bold and italicized text
Entire paragraphs in bold or italics
Lack of alt text or hover tags for images
Using "here" or "click here" before a URL
Images of code or text

I have done some editing to questions/answers to make them more accessible but I have come across users that question why the edit was done or roll it back. An "Accessibility" page like the Markdown Help page would go a long way in helping users post and edit questions/answers.

Note: Users' indifference or not being made aware of why accessibility is important has existed for a while as shown in an answer to "Does Stack Overflow strive to meet accessibility standards?".
