# Let's get these tags [locked] down - do we need them all?

I just wrote a question about post notices on locked questions. When using the tag picker, I realized that we have three tags that are all really versions of the same tag:

locked - 86
locked-questions - 152
locked-answers - 8

The first of these is ambiguous. While most of the questions are about locks on posts, there are a few questions about vote locks, which has its own tag (locked-votes). These errant questions should be retagged leaving only post-related tags.

The second has the most uses but it is also too specific. Many of the questions here aren't only about locked questions. Many of them are about both question and answer locks (for example: Allow moderators to fine-tune the effects of a lock).

The third has few questions and, like the questions version, they aren't necessarily specific only to answers.

So, my suggestion

Review all of the existing questions to be certain they're tagged correctly (particularly in the locked group).
Merge and synonymize all three into a new tag - locked-posts. This will hopefully prevent it from being used for non-post-related questions.

If locked seems too ambiguous to synonymize, we could just merge that one without the synonym.
