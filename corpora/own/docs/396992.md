# User profile is not loading Stack Exchange reputation league page

It appears there's a bug on the stackexchange.com reputation league page. When navigating to the "All Time" section for Stack Overflow and Meta Stack Exchange via the drop-down list or by entering the URL in the browser, users typically expect to see their user profile at the top of the sections, provided they have an account on the respective site. However, currently, the user profile fails to load, and instead, a loader is displayed with the tool-tip "Loading user information".

This issue seems to persist exclusively for Stack Overflow and Meta Stack Exchange, although similar problems may occur on other sites as well.
