# "bounty start" with reputation entry is removed from the bounty post's timeline

When there is a bounty added for a question, previously there are three entries are added to the post's timeline, such as :

"bounty started"
"notice added" with a comment provided by the person who initiated the bounty
"bounty start" with the bounty reputation

Screenshot from one of an old posts, which has the "bounty start" entry with the reputation, circled in red.

But in recent times the "bounty start" with reputation entry is removed from the bounty post's timeline.

The entry contains the detail about the bounty reward reputation, it will help in the future to know how much reputation was allocated as a bounty for the post in the timeline.

The "bounty start" entry is not available in the recent bounty questions timeline.
