# Adding indented text after a 2nd-level list in a nested list messes up the spacing of the outer list

If I have a bulleted list and I want to add some indented text after a certain element, I do something like this:

- Point 1
- Point 2

  Indented text

- Point 3

..which renders like this:

Point 1

Point 2

Indented text

Point 3

So for, so good.

Now, if I have a second-level list like this:

Point 1

Point 1.1
point 1.2

Point 2

..and I want to add some indented text before Point 2, I do something like this:

- Point 1
  - Point 1.1
  - point 1.2

  Indented text
- Point 2

I expect to see some spacing above Indented text just like the first example. However, when I do that, the line spacing gets messed up; no spacing above Indented text and some additional spacing is added above the child/2nd-level list.
