# Posting a draft should not lead to a captcha

Sometimes, I write a question which I do not immediately post (for various reasons), but choose to save it as a draft instead. When I open the 'Ask Question' page again, and click the 'Post Your Question' button too soon, I first have to solve a captcha before I can submit the question.

I understand the need for some rate limiting here, but when I spent a few minutes writing a draft, that should be taken into account. Drafts are only saved after 45 seconds so they should not be tripping the 'post within 5 seconds after opening the page' captcha.

(I'm not sure if answer drafts exhibit the same behaviour, but this feature request would apply to answers as well.)
