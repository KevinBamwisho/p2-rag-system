# Using the "Search all sites" on the "All sites" page does something unexpected

I wanted to find the link to the site the name of which I forgot but knew a term it has to do with, so I went to https://stackexchange.com/sites which can be found by clicking "All sites" tab link when you are on the https://stackexchange.com/ page. The search bar on top says "Search all sites", and so I assumed it would do as it says, and not something like "Search on Meta Stack Exchange" like you see above here, on MSE. The result was several thousand questions and answers on all the network sites which contained the search term. For example, try searching for "gaming" (545'771 results, none related to Arqade.SE on the first page).

Following the principle of least astonishment, I propose to add a search among the names, descriptions and a set of thesaurus words to find the Stack Exchange site one might be looking for, instead of just searching for the entered keyword all over the network.

This is a UX problem basically, and, to clarify, I'm proposing to add a prominent search bar which in no uncertain terms says something that means you will receive search results for the sites on the network, not the posts.
