# A link in the top bar to site analytics

I just gained the 25k privilege and from reading the Help Center page I was wondering where the link to the /site-analytics would be...?

Turns out there isn't a link in the top bar like for the other privileges (e.g: review queues, moderator tools)... This hits me as frustrating, I've always enjoyed the way all the functionalities integrate nicely into the UI. But now, for the last privilege, I have to navigate to the Help Center page to find the link or write an URL... This clicking away from the top bar, away from the user profile, away from all the things that make my experience an immersion, is just a anticlimactic.

Could we have better integration of the 25k privilege? And where would be the optimal place to put that hypothetical link?
