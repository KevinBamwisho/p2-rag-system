# New privilege tracker - 'Track the next one' banner misplaced when you've also earned a new badge

I'll admit that this is a rare case, but when you've earned a new privilege and a badge you've tracked, the dark blue 'banner' which contains the 'Track the next one' button seems to be positioned too high, leaving an 'empty' gray line at the bottom of the widget. I suspect this happens because the height of the badge tracker widget in this case is higher than would be normally.

Tested with the latest Safari and Firefox on macOS Mojave.
