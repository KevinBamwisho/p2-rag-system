# Low quality review audits should take question/answer filter mode into account

In some review queues like First Posts or Low Quality Posts, there is the ability to set a filter by the post type: question or answer. In case of audit there can be a wrong post type for review. For instance, I chose only questions, but I see answer for review:

And the opposite:

A similar bug was fixed on Stack Overflow, where the Low Quality Posts queue is always filtered only to answers for everyone but question audits were appearing; it should be implemented on other sites too.

This was already reported at Audits doesn't take into consideration the filter, but that was closed as a duplicate of a more general request about filters (including tag filters), which was marked as by design because filtering via tags would be difficult. However, it is much easier to filter answers and questions, as demonstrated by the above Stack Overflow bug fix.

Currently, one can accidentally take the wrong action if they've applied such a filter but the wrong type of post appears (e.g. negatively review a known-good question audit that they thought was a non-answer since they filtered only to answers, or positively review a known-bad answer audit that was a non-answer but they thought was a new question since they filtered only to questions).

Can this please be implemented?

Update: Per Catija's comment, as the First Posts queue was split into separate queues for questions and answers, this is no longer an issue for that queue. However, this still continues to be an issue on the low quality review queue on sites other than those where Triage is enabled. Can this please be fixed there?
