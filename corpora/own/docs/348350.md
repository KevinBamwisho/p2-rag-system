# User Search results not sorted by reputation

The user search feature used to sort users by reputation in the given timeframe both when listing all users and when searching specific user names. This allowed us to find the user with the highest reputation and a specific name, or search for specific high reputation users when we knew their name but not their user ID.

Now, it only appears to sort users by reputation when a search term is not entered, otherwise it is sorted by user ID.
