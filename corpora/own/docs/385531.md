# Reputation gain from the last answer displays the daily reputation

When navigating to the reputation tab in my profile after not doing so for a while, the latest answer with reputation gain displays the gain for the entire day.

E.g., consider this screenshot - my daily gain (at the time the screenshot was taken) was 30 rep - 20 for the first answer and another 10 for the second. However, the top answer displays +30. Refreshing the page corrects the display.
