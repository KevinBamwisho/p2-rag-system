# Contradictory messages when question is closed and comments disabled

I spotted this on Super User but I believe the same or similar messages can appear on any SE site. Below are two messages that contradict each other. They appeared in a single post, one under the other:

(For the record, the screenshot is from this question.)

The first message states [emphasis mine]:

Closed. This question […] is not currently accepting answers.

The second message states [again, emphasis mine]:

Locked […]. Comments on this question have been disabled, but it is still accepting new answers and other interactions.

The question at the time was not accepting new answers. The first message was right, the second message was wrong in this matter. The second message should be corrected. It should reflect the actual status of the question. It should not contradict with the first message.
