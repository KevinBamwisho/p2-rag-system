# Fully enable keyboard shortcuts in review queues

I'm using the keyboard shortcuts quite often to vote posts up or down, and flagging or close-voting them.

In the review queues, especially the First Posts and Late Answers, where these kind of actions are encouraged, the keyboard shortcuts don't work.

I've noticed that they sometimes (but not always) work if you reload the page of a specific review item (but never on subsequent reviews). It seems related to loading the post into the page dynamically via AJAX.

Note that I'm not asking for Keyboard shortcuts for review queues; IMHO that's a bad idea since it encourages robo-reviewing.
