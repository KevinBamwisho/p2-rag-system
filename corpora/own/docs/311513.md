# The starting day of the site is displaying wrongly

In Users page -> Reputation tab -> all option is for sorting the users by reputation in descending order from the starting day of the site to today. When hover on the all option the tooltip is displaying the text, in the format of starting-date-of-the-site to today. Currently the starting date of the site is displaying wrongly.

For an example, in Stack Overflow previously it was displayed as 2008-07-31 to today, currently it is displaying as 2000-01-01 to today. The issue is for all Stack Exchange sites.
